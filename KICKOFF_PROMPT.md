# Kickoff prompt

**Usually not needed.** AI Studio reads `AGENTS.md` on import and starts the intake on its own. Use this only if it
does not: paste it as the first message in AI Studio Build. If you have a PRD or product brief, paste or upload it
in the same message.

---

```
Before doing anything, read AGENTS.md, the numbered files in /guidelines (01 to 08),
guidelines/design-system/README.md, and project/BRIEF.md.
If you changed any files before this message, list them and restore them (keep package-lock.json only).
Do not modify any code yet. Follow the intake process in guidelines/01-intake-questions.md.
If I paste a PRD below, use "If the user shares a PRD" and ask only what it does not answer.
Otherwise ask me the Phase 1 questions now, wait for my answers, then continue phase by phase.
When intake is done, fill project/BRIEF.md and ask me to confirm before building.
After I say go, run the project setup in guidelines/01-intake-questions.md first
(it replaces README.md with a README for this product), then build.
```
